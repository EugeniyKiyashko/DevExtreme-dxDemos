dxRangeSelector: the slider marker text leaves its marker in RTL mode

What happens. With rtlEnabled: true the text of both slider markers is drawn to the left of its marker, shifted by its own width: the left marker shows only the tail of "February 5", the right one prints "March 5" over the scale next to an empty marker. The marker rectangle and its tracker are placed right, only the text is off. The picture is the same on 23.2, 26.1 and 26.2, and it also appears when rtlEnabled is switched on at runtime.

Why. The renderer turns align: 'left' into text-anchor using the direction it knows at the moment of the call: start in LTR, end in RTL. The marker set the alignment in its constructor, which runs while the widget is being initialized, before the renderer receives rtlEnabled. So the label kept text-anchor="start"; once the root got direction="rtl", start anchors the right edge of the text, and the text goes to the left of the point where the marker expects it to begin.

The fix. The alignment moves from the constructor to applyOptions, which runs on every update after the renderer options are applied, so the anchor follows the current direction both on creation and when rtlEnabled changes later.

The change

 
range_selector/slider_marker.ts
  function SliderMarker(renderer, root, isLeftPointer) {
    …
-   that._label = renderer.text().attr({ align: 'left' }).append(that._group);
+   that._label = renderer.text().append(that._group);
    …
  }

  applyOptions(options, screenRange) {
    …
-   that._label.css(patchFontOptions(options.font));
+   that._label.attr({ align: 'left' }).css(patchFontOptions(options.font));
    that._update();
  }

Frames

Both frames run the sample from the issue on 26.2.0 built from the same tree, the only difference between the two bundles is the change above. Each frame creates the range selector with rtlEnabled: true when it loads; the buttons send the same action to both frames, so the runtime switch can be compared as well. The log at the bottom of each frame records, after every action, where the text of each marker lies against its marker rectangle.
